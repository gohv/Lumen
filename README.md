# Lumen

Modern, animated action bars and unit orbs for **World of Warcraft: Forever**. Round glass buttons on curved bars instead of grids of squares, with cooldowns that change color and a living 3D avatar.

> Built for WoW Forever (`## Interface: 16001`, Midnight engine). Lumen handles the engine's in-combat "secret values" by letting the client color cooldowns and fill bars natively.

## Features

**Action bars**
- Three curved bars (arc or straight) of round glass buttons, using your normal keybinds and stance/form paging
- Cooldown rings that change color as they run out (violet → pink → amber → mint in the default theme)
- A bloom when an ability is ready, plus a center-screen pulse for long cooldowns
- Spinning comet on spell alerts (procs), ripple and squish on every press
- macOS-dock-style magnification on hover
- Red tint when out of range, blue when out of mana, grey when unusable

**Living avatar**
- Your 3D character in a glass orb that reacts to what you're doing: ready stance and darting glances in combat, flinches when hit, a roar or flex when a fight ends, sits down in town, sleeps when AFK, mirrors your `/emotes`
- Liquid health fill, power bar, and health/mana numbers always visible
- Replaces Blizzard's player frame: left-click targets you, right-click opens your menu

**Target orb**
- The target's live 3D model with liquid health, a glow colored by reaction (or class color for players), and a gold ring for elites (silver for rares)
- Pulses red when it's attacking you; flinches, flashes and shakes when hit; plays its death animation
- Shows name, level, health, mana and who it is targeting
- Replaces Blizzard's target frame; combo points move next to the orb

**Cast arcs and aura bubbles**
- A ring around each orb fills while casting and drains while channeling, flashing on success and red on interrupt. On your target, red means you can interrupt it and grey means you can't.
- Buffs and debuffs float as bubbles around the orbs, with timer rings, stack counts and tooltips

**XP bar**
- Ten segments, XP to level, percent, estimated kills and time to level, rested XP, and floating "+XP" numbers

**Everything else**
- Five themes: Aurora, Ember, Frost, Neon, Verdant
- An edit mode to drag, resize (mouse wheel) and nudge (arrow keys) every element, with grid snapping. It also opens alongside Blizzard's Edit Mode.
- An options window: `/lumen`, or Esc → Options → AddOns → Lumen

## Install

1. Download `Lumen-x.y.z.zip` from [Releases](https://github.com/gohv/Lumen/releases).
2. Unzip it into `World of Warcraft/_forever_/Interface/AddOns/` so that you have `AddOns/Lumen/Lumen.toc`.
3. **Fully restart WoW.** A `/reload` doesn't pick up an addon's new files.

## Commands

| Command | What it does |
|---|---|
| `/lumen` | Open the options window |
| `/lumen move` | Edit mode: drag, resize, nudge, right-click to reset |
| `/lumen test` | Preview cooldowns, procs and the pulse |
| `/lumen avatar demo` | Run the avatar through every mood |
| `/lumen theme <name>` | aurora, ember, frost, neon or verdant |
| `/lumen debug` | Show which modules loaded and how the last cast was drawn |
| `/lumen help` | List all commands |

## Notes

- Lumen hides Blizzard's main and bottom action bars, player frame, target frame, cast bar and XP bar while its own replacements are active. Each one can be brought back from the options window.
- During combat, WoW hides some values from addons (cooldown timings, health, aura details). Lumen still shows them through the client's own rendering, but some text (such as thousands separators) may be simplified in combat.
- Right-clicking a buff bubble does not cancel it: WoW only allows that from Blizzard's own secure buttons.

## Development

- `tests/harness.lua` loads the whole addon against a mocked WoW API and drives events, slash commands, edit mode and the options window. Run `lua5.1 tests/harness.lua .`, or set `SECRET=1` to make every combat value "secret". CI runs both on every push.
- `tools/gen_textures.py OUT_DIR PREVIEW_DIR` regenerates every texture in `Media/` (requires numpy and Pillow).
